PINA COLADA — SURF SCHOOL & TUK TUK
==================================

Files:
- index.html     Main page content
- style.css      Colors, responsive layout, typography and animations
- script.js      Mobile navigation, scroll reveal and footer year
- assets/        Logo and surf lesson image

FEATURES
- Tropical beach + adventure visual style
- Responsive mobile navigation
- Hero photo, animated entrance and floating stamp
- Scroll reveal animations (respects reduced-motion preferences)
- Surf lessons, rental, private/small group and tuk tuk/pick-up sections
- WhatsApp booking links for 0765288241
- Google Maps embed and button to the exact map link supplied
- Reviews section that invites genuine reviews instead of inventing customer testimonials
- Accessible labels and image descriptions

PUBLISH TO YOUR EXISTING GITHUB PAGES REPOSITORY
1. Download and unzip this package.
2. Open your GitHub repository: dew78010-prog/pina-colada.
3. Back up the current files if you want to keep a copy.
4. Upload/replace index.html, style.css, script.js, and the assets folder in the repository root.
5. Commit the changes.
6. Wait a few minutes, then refresh https://dew78010-prog.github.io/pina-colada/ . GitHub Pages may take up to 10 minutes to publish changes.

IMPORTANT
- The site is a static HTML/CSS/JS website for GitHub Pages.
- Google Fonts require an internet connection; fallback fonts are included.
- The embedded map shows the Kudawella area. The separate Google Maps button opens the exact map link provided by the owner.
- The review area is intentionally not filled with fabricated reviews. Add real customer feedback only after receiving permission.
- Check all service details and booking arrangements before publishing to customers.
